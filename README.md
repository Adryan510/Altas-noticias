# 📰 Altas Notícias

Portal de notícias demonstrativo desenvolvido como projeto acadêmico durante os estudos de Front-end.

## Tecnologias
- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- JavaScript (filtro de pesquisa simples)

## Recursos
- Navegação responsiva com menu recolhível
- Carrossel de destaques
- Cards de notícias
- Acordeão de categorias
- Pesquisa que filtra os cards por texto
- Layout adaptável a telas menores

## Como executar localmente
Baixe ou clone este repositório e abra `index.html` no navegador. Os arquivos CSS, JavaScript, ícones e imagens são mantidos localmente no projeto.

## Publicação
Este projeto pode ser publicado com GitHub Pages usando a branch `main` e a pasta `/(root)`.

## Observação
Os textos apresentados são ilustrativos e não representam notícias reais verificadas. As imagens são usadas como recursos visuais do projeto acadêmico.
