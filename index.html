Sobre o portal

O Altas Notícias é um projeto acadêmico desenvolvido para praticar a criação de páginas web com HTML, CSS e Bootstrap. A proposta é organizar conteúdos em uma interface simples, responsiva e fácil de navegar.

Os textos desta demonstração são ilustrativos e não representam notícias jornalísticas verificadas.
